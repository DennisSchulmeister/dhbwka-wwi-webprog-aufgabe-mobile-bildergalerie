# Webprogrammierung / Aufgabe / Mobile Bildergalerie

Dies ist eine **Übungsaufgabe** aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *Responsive Webdesign*.

Ausgehend von vorgegebenem HTML wird eine Bildergalerie im Mobile-First-Ansatz gestylt und über Media Queries für Tablet- und Desktop-Ansichten erweitert.

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
